# Source map

External factual claims used by GhostTrace are mapped here to primary sources.
GhostTrace's own empirical claims are mapped to released artifacts in
[`CLAIM_LEDGER.md`](../CLAIM_LEDGER.md). Links were checked on 2026-09-21.

| Claim used by GhostTrace | Primary source |
|---|---|
| A same-base student can acquire a teacher trait from semantically unrelated data, including after explicit-content filtering | Cloud et al., [Nature 652, 615–621 (2026)](https://www.nature.com/articles/s41586-026-10319-8) and [arXiv:2507.14805](https://arxiv.org/abs/2507.14805) |
| Compatible output heads, rather than identical initialization alone, govern the controlled MNIST transfer setting | Brockers et al., [arXiv:2605.23645](https://arxiv.org/abs/2605.23645) |
| Divergence-token masking and prompt paraphrasing suppress transfer in the tested settings | Schrodi et al., [arXiv:2509.23886](https://arxiv.org/abs/2509.23886) |
| Subliminal prompting can produce weakening but persistent bias across a six-agent prompting network | Weckbecker et al., [arXiv:2603.00131](https://arxiv.org/abs/2603.00131) |
| Anchored recursive distillation contracts toward the base teacher under the paper's assumptions | Flouro and Chadwick, [arXiv:2601.13100](https://arxiv.org/abs/2601.13100) |
| Iterative SFT and synthetic-document fine-tuning of seeded traits mostly decays or remains constant in the reported experiments | Roe et al., [arXiv:2605.01130](https://arxiv.org/abs/2605.01130) |
| Recursive training on generated data can cause distributional model collapse | Shumailov et al., [Nature 631, 755–759 (2024)](https://www.nature.com/articles/s41586-024-07566-y) |

The model-collapse article received a 2025 author correction, which is reflected
in the current Nature article linked above. These sources define context and
comparison points; they do not validate GhostTrace's own results.
